“本节点”是当前进程，来源地址列显示它的监听或上游地址；下游节点每个 v4 会话一行，节点重连后会换一个新会话号。版本列来自节点连接时上报的软件版本，旧版本节点不提供该信息时显示“—”。下游的来源地址优先显示网关（雷池、nginx 等）转发的对端 IP，没有网关时显示直接连到本机的 TCP 地址。“IP 归属”在页面加载后由浏览器直接向公共 IP 归属接口查询来源 IP 的供应商和地理位置，不经过本服务；局域网、回环和无法识别的地址不查询，查询会把来源 IP 发送给该第三方服务。“管理服务”打开本节点或下游节点的服务列表，可在弹窗内增删改该节点自己的 [[proxies]]；“断开”只关闭当前会话，节点会按自己的重连间隔重新连上。“上级修改”列显示该节点是否允许它的上一跳修改本地服务：本节点可在顶部“上级修改”中切换，切换会重连上游会话；下游节点显示它自己上报的开关状态，只读时按钮变为“查看服务”。

接口列表

方法路径认证说明
GET/api/statusBearer进程状态：名称、传输、上游、连通性、服务数、下游节点数、上级修改开关及是否可编辑、版本、配置文件、运行时长、环境变量
GET/api/proxiesBearer列出本地服务、auth_header 明文及来源；加 ?node= 或 ?session= 时列出该下游节点自己的服务
GET/api/routesBearer生效中的路由表，包含 v4 会话
GET/api/sessionsBearer已连接的下游节点：会话号、节点、版本、网关转发的来源 IP、TCP 对端、角色、连接时长、所属域名与是否可管理
PUT/api/proxies/{name}Bearer新增或替换服务，请求体 {"domain":"…","local_addr":"…","auth_header":"…"}；省略或 null 表示关闭访客认证。带 ?node=/?session= 时写入下游节点
PUT/api/settings/allow-upstream-modifyBearer开关本节点是否允许上级修改本地服务，请求体 {"allowed":true}；保存后会重连上游会话，无上游、由环境变量接管或 HT_PROXIES 只读时返回 409
DELETE/api/proxies/{name}Bearer删除服务；带 ?node=/?session= 时删除下游节点的服务
DELETE/api/sessions/{id}Bearer断开一个下游会话；节点会按自己的重连间隔重新连上
GET/Basic本管理页面（唯一的 Basic 资源，其余接口统一用 Bearer）

所有 /api/* 使用 Authorization: Bearer <token>；页面本身使用 HTTP Basic，用户名 ht，密码为 token。错误响应为 {"error":"…","request_id":"…"}。下游参数 node 与 session 可同时给出，必须指向同一会话；不给出时只操作本进程。管理响应带 Cache-Control: no-store，但 auth_header 以明文返回，管理面必须通过 HTTPS 访问；同一控制面的节点需运行同一版本。
